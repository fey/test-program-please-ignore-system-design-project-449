# Сервис такси на потоке событий

[![hexlet-check](https://github.com/fey/test-program-please-ignore-system-design-project-449/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/fey/test-program-please-ignore-system-design-project-449/actions)

Спроектируйте развитие работающего такси. Пассажиры должны получать
уведомления вовремя, а операционная команда видеть свежие показатели.
Обоснуйте взаимодействие компонентов, подключите событийную обработку
и проверьте независимый выпуск, повторы и восстановление.

Учебный проект Хекслета: https://ru.hexlet.io/programs/test-program-please-ignore-system-design
